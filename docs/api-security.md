# 接口登录与图片文件保护

商铺、优惠券和商铺类型的 GET 查询继续公开；相应写操作、图片上传及删除须先登录。遵循当前选择：这里不区分管理员、商户或普通用户，任何已登录用户都可以执行商铺和优惠券写入；如需多用户部署，应另行实现角色及商铺归属权限。登录失败沿用现有 401 响应。

新图片仅允许 5 MB 内的 JPEG、PNG、GIF、WebP 文件，校验扩展名及文件头；按 `/blogs/users/{用户ID}/{随机UUID}.{后缀}` 保存到 `hmdp.upload.dir` 配置的根目录，未配置时沿用原目录。删除接口仅接受当前用户的路径，并兼容前端传入的 `/imgs` 前缀。历史文件不带归属信息，保留读取但不能通过此接口删除。检查路径各层符号链接和目录边界；该检查不防范拥有服务器文件系统写权限的本地用户并发替换目录，应保护上传根目录及父目录的操作系统权限。图片头检查不能证明内容是完整、无恶意的图像。

运行 Java 8 的 `mvn '-Dtest=ApiSecurityTest' test` 验证匿名请求、公开查询、上传删除和跨用户隔离。符号链接测试依赖当前 Windows 权限，无法创建时该分支会跳过。测试使用 MockMvc 和临时目录，不代表浏览器、Nginx 或真实多用户端到端验证。
